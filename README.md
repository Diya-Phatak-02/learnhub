# LearnHub - Online Course Platform

Students can register, log in, browse courses and enroll online.

## Features
- Registration and login (bcrypt hashing, JWT)
- Courses stored in MongoDB Atlas
- Simulated payment gateway (demo mode)
- Modern responsive UI

## Tech Stack
HTML, CSS, JavaScript, Node.js, Express, MongoDB Atlas, Render, GitHub

## Live Link
https://learnhub-ddyi.onrender.com

## Run Locally
1. npm install
2. Create .env with MONGO_URI and JWT_SECRET
3. npm run dev
